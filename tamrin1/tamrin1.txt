سوال ۱:

۱. Git چیست و چه کاربردی دارد؟

Git یک سیستم کنترل نسخه است که برای مدیریت و ثبت تغییرات فایل‌ها و پروژه‌ها استفاده می‌شود. با استفاده از Git می‌توانم تغییراتی که در پروژه ایجاد می‌کنم ثبت کنم و در صورت نیاز به نسخه‌های قبلی پروژه برگردم. همچنین Git به من کمک می‌کند تغییرات مختلف پروژه را مدیریت کنم و بدانم چه تغییراتی در چه زمانی انجام شده است.

۲. GitHub چیست و چه تفاوتی با Git دارد؟

GitHub یک پلتفرم آنلاین برای نگهداری و مدیریت پروژه‌هایی است که معمولاً با Git مدیریت می‌شوند. من می‌توانم Repository پروژه‌ام را در GitHub قرار بدهم تا فایل‌ها و تغییرات پروژه به صورت آنلاین ذخیره شوند و بتوانم آن‌ها را با دیگران به اشتراک بگذارم.

تفاوت Git و GitHub این است که Git یک سیستم کنترل نسخه است که روی کامپیوتر هم قابل استفاده است و تغییرات پروژه را مدیریت می‌کند، اما GitHub یک سرویس آنلاین است که برای ذخیره، مدیریت و به اشتراک گذاشتن Repositoryهای Git استفاده می‌شود.
