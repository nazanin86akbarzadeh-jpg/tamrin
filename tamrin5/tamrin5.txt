سوال ۵:

۱. GET چیست؟

GET یکی از متدهای HTTP است که معمولاً برای گرفتن اطلاعات از سرور استفاده می‌شود. در GET اطلاعات مورد نیاز می‌توانند در URL قرار بگیرند. برای مثال وقتی در یک سایت چیزی را جستجو می‌کنم، عبارت جستجو می‌تواند در URL قرار بگیرد و برای سرور ارسال شود.

۲. POST چیست؟

POST یکی دیگر از متدهای HTTP است که معمولاً برای فرستادن اطلاعات به سرور استفاده می‌شود. اطلاعاتی که با POST ارسال می‌شوند معمولاً در قسمت Body درخواست قرار می‌گیرند. از POST برای کارهایی مثل ثبت‌نام، ارسال فرم یا ایجاد اطلاعات جدید استفاده می‌شود.

۳. چه تفاوتی بین GET و POST وجود دارد؟

GET بیشتر برای گرفتن اطلاعات از سرور استفاده می‌شود و اطلاعات آن می‌توانند در URL دیده شوند. POST بیشتر برای فرستادن اطلاعات به سرور استفاده می‌شود و اطلاعات آن معمولاً داخل Body درخواست قرار می‌گیرند و در URL دیده نمی‌شوند. البته POST به تنهایی باعث رمزنگاری اطلاعات نمی‌شود و برای اطلاعات حساس باید از HTTPS استفاده شود.

۴. برای چه نوع درخواست‌هایی معمولاً از GET استفاده می‌کنیم؟

از GET زمانی استفاده می‌کنیم که بخواهیم اطلاعاتی را از سرور بگیریم، مثل جستجوی یک محصول، گرفتن لیست محصولات یا دریافت اطلاعات از یک API.

مثلا: GET /products

در این مثال از GET برای دریافت اطلاعات محصولات استفاده می‌شود.

۵. برای چه نوع درخواست‌هایی معمولاً از POST استفاده می‌کنیم؟

از POST زمانی استفاده می‌کنیم که بخواهیم اطلاعاتی را برای سرور بفرستیم یا اطلاعات جدیدی ایجاد کنیم، مثل ثبت‌نام کاربر، ارسال فرم یا ایجاد یک حساب جدید.

مثلا: POST /users

در این مثال اطلاعات یک کاربر می‌تواند برای ایجاد یک کاربر جدید به سرور ارسال شود.
