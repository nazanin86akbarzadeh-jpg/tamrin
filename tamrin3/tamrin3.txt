سوال ۳: 

۱. HTTP چیست؟

HTTP مخفف HyperText Transfer Protocol است و به معنی پروتکل انتقال ابرمتن است. HTTP روشی برای ارتباط بین مرورگر و سرور است. وقتی یک سایت را باز می‌کنم، مرورگر درخواست را برای سرور می‌فرستد و سرور اطلاعات مورد نیاز مثل متن، عکس و فایل‌های صفحه را برای مرورگر ارسال می‌کند. در HTTP اطلاعات به صورت رمزنگاری‌شده منتقل نمی‌شوند.

۲. HTTPS چیست؟

HTTPS مخفف HyperText Transfer Protocol Secure است و نسخه امن‌تر HTTP محسوب می‌شود. در HTTPS اطلاعاتی که بین مرورگر و سرور رد و بدل می‌شوند، رمزنگاری می‌شوند و امنیت بیشتری دارند. به همین دلیل برای سایت‌هایی که اطلاعات شخصی، رمز عبور یا اطلاعات بانکی دریافت می‌کنند، استفاده از HTTPS اهمیت زیادی دارد.

۳. چه تفاوتی بین HTTP و HTTPS وجود دارد؟

تفاوت اصلی HTTP و HTTPS در امنیت آن‌هاست. در HTTP اطلاعات رمزنگاری نمی‌شوند، ولی در HTTPS اطلاعات هنگام انتقال رمزنگاری می‌شوند. بنابراین HTTPS امنیت بیشتری دارد و برای انتقال اطلاعات مهم و حساس مناسب‌تر است.

۴. چرا امروزه بیشتر وب‌سایت‌ها از HTTPS استفاده می‌کنند؟

چون اطلاعات کاربران باید در هنگام انتقال امنیت بیشتری داشته باشند. HTTPS کمک می‌کند اطلاعاتی مثل رمز عبور، اطلاعات شخصی و اطلاعات پرداخت راحت در اختیار افراد غیرمجاز قرار نگیرند. به همین دلیل امروزه بیشتر سایت‌ها از HTTPS استفاده می‌کنند.
