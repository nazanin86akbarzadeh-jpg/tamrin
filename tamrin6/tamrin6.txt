سوال ۶:

۱. JSON چیست؟

JSON مخفف JavaScript Object Notation است و یک روش برای ذخیره و انتقال اطلاعات است. JSON ساختار ساده‌ای دارد و اطلاعات را معمولاً به صورت کلید و مقدار یا Key-Value نمایش می‌دهد. JSON در برنامه‌های مختلف و مخصوصاً APIها کاربرد زیادی دارد.

۲. XML چیست؟

XML مخفف Extensible Markup Language است و برای ذخیره و انتقال اطلاعات استفاده می‌شود. در XML اطلاعات با استفاده از تگ‌ها نوشته می‌شوند و هر تگ مشخص می‌کند چه نوع اطلاعاتی داخل آن قرار دارد.

۳. JSON و XML چه کاربردی دارند؟

هر دو برای ذخیره و انتقال اطلاعات بین برنامه‌ها، سیستم‌ها و سرورها استفاده می‌شوند. یکی از کاربردهای مهم آن‌ها انتقال اطلاعات بین کلاینت و سرور در APIها است. JSON بیشتر در برنامه‌ها و APIهای وب امروزی استفاده می‌شود و XML هم در بعضی سیستم‌ها و سرویس‌ها کاربرد دارد.

۴. چه تفاوت‌هایی با یکدیگر دارند؟

تفاوت اصلی JSON و XML در شکل نوشتن اطلاعات است. در JSON اطلاعات بیشتر به صورت کلید و مقدار نوشته می‌شوند و معمولاً ساختار ساده‌تر و کم‌حجم‌تری دارد. در XML اطلاعات داخل تگ‌ها قرار می‌گیرند و معمولاً نسبت به JSON طولانی‌تر است. هر دو می‌توانند اطلاعات مشابهی را ذخیره و منتقل کنند، ولی روش نمایش آن‌ها با هم فرق دارد.

۵. اطلاعات یک Student با JSON:

{
"studentNumber": 1001,
"firstName": "Nazanin",
"lastName": "Akbarzade",
"field": "Multimedia",
"average": 19.25
}

همون اطلاعات Student با XML:

<Student>
    <StudentNumber>1001</StudentNumber>
    <FirstName>Nazanin</FirstName>
    <LastName>Akbarzade</LastName>
    <Field>Multimedia</Field>
    <Average>19.25</Average>
</Student>
